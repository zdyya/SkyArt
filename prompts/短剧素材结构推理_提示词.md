# 短剧素材结构推理提示词

第二步。输入是第一步写下来的文字，不给视频。分四轮，每轮单独调用。

设计原则和字段来历见 `短剧素材拆解_执行说明.md`。

---

## 第一轮：整条脉络

输入：全部段落记录——每段的场景、人物、按时间排列的事件（含台词原文）、段落叙述。

```
你要从一条短剧广告素材的拆解记录里，理出它的剧情脉络。

输入是这条素材每一段的完整记录：场景、人物、按时间排列的事件、段落叙述。
你看不到视频，只能用这些文字。

## 规则

1. 「这一段推进了什么」写这一段之后局面跟之前有什么不一样，不写这一段
   拍了什么。
2. 题材要有依据，依据的原文必须照抄输入里的字，一个字都不能改。台词是
   英文就照抄英文，**不要把中文的画面描述或段落叙述当成台词填进去**，
   也不要自己翻译。这一栏会被拿去跟第一步的记录逐字比对，改过的字算编造。
   找不到能引的原文就填「无法判断」，依据填空数组。
3. 依据的「时间」填那句原文在输入里标的绝对时间，不要填 0。
4. 填「其他」的时候，在「理由」里写出你认为它应该叫什么，5 字以内。
5. 题材填两级。一级按这条素材的主线冲突来分：
   - 都市爱情：主线是两个人的关系怎么成立或破裂
   - 复仇打脸：主线是主角被亏待过，后面要讨回来
   - 权力幻想：主线是主角的身份或能力远高于旁人所知
   - 家庭伦理：主线是亲子、婆媳、兄弟姐妹之间的争夺
   一条素材同时像两类，选戏份最多的那条主线。二级从下面的词表选，
   跟一级不必对应——同一个二级可以落在不同一级里。
6. 只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字。

## 输出格式

{
  "剧情时间线": [
    {"段": 整数, "这一段推进了什么": "20 字以内"}
  ],
  "题材": {
    "一级": "都市爱情|复仇打脸|权力幻想|家庭伦理|其他|无法判断",
    "二级": "契约婚姻|禁忌关系|霸总富豪|黑帮教父|隐藏身份|重生换身|复仇虐渣|狼人阿尔法|落难千金|隐婚生子|其他|无法判断",
    "依据": [{"段": 整数, "时间": 秒数, "类型": "台词|画面|屏幕文字", "原文": "照抄输入里的字"}],
    "理由": "一句话，20 字以内"
  }
}

一条 5 段的素材写出来是这样。示例里的段数和内容是那条素材的实际情况，
不是标准答案的形状。

{

    {"段": 1, "这一段推进了什么": "女主被婆家赶出门，无处可去"},
```

## 第二轮：逐段定性

按窗循环，每窗最多 4 段。输入：整条素材的剧情时间线，加这一窗每段的完整记录。

```
你要给一条短剧广告素材里的几个片段各写一份规格。

这些片段将来要被拿去重新拼装成新的广告。你写的每一栏都要能回答「这个片段
能不能用、放在哪里用」，不是在写剧情简介。

输入分两部分：整条素材的剧情时间线，每段一行，让你知道手上这几段处在整条
的什么位置；然后是你这一次要处理的那几段的完整记录——场景、人物、按时间
排列的事件、段落叙述。

**只写你手上这几段。**时间线里的其他段是背景，不要去写那些段，它们由别的
调用处理。

## 规则

1. 时间一律用绝对时间。每段记录的开头写着这一段从第几秒起，段内事件的
   时间要加上这个起点。
2. 每一处判断都要附依据，依据写成数组，一到三条：

       "依据": [
         {"时间": 81.5, "类型": "台词", "原文": "I'm actually a billionaire"},
         {"时间": 83.0, "类型": "画面", "原文": "镜头切到停在门口的黑色轿车"}
       ]

   「类型」只能填台词、画面、屏幕文字三种之一。「原文」照抄输入里的字，
   一个字都不要改，不要翻译、不要概括、不要拼接两处内容。这一栏会被拿去
   跟第一步的记录逐字比对，改过的字算编造。
3. **依据里不许写你的判断。**「形成反差」「情绪张力拉满」这类是解读，不是
   证据。依据只放原文，判断放在值里，要解释就写在「理由」那一栏。
4. **「这一段最强的一刻是什么」用你自己的话写，不要往固定词上靠。**不要写
   「反转」「爽点」「高潮」「情绪爆发」这类概括词，写具体发生了什么：谁对
   谁做了什么、谁知道了什么、谁失去了什么。这一栏后面要拿来归类，用了概括
   词就归不出东西。
5. 判不出来的填 null，依据填空数组。这是正确答案，不是失败。宁可填 null，
   不要凭常识补一个看起来合理的——短剧套路很强，按套路猜十次能对七次，
   但那三次错的没法被发现。
6. 只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字。

{

      "结尾留没留悬念": "留了|没留",

        {"时间": 秒数,

         "是什么": "用你自己的话，20 字以内",
         "有旁人在看吗": "有|无",
         "主角在这一刻是": "施加方|承受方|都不是",

      "阶层落差依据": [...],

    }

段数组要包含你手上的每一段，一段不少，按段号升序。

## 怎么判

**这一段最强的一刻**：这一段里如果只能留一秒给观众看，留哪一秒。判断办法是
看第一步记录的「这一刻发生了什么变化」那一栏，挑变化最大的那一条。整段没有
任何变化，比如全程只是两个人平静说话，这一栏和时间都填 null。

**结尾留没留悬念**：这一段的最后一个镜头之后，观众有没有一个悬着的问题。
门要被打开、有人正走过来、有人话说一半、有人拿出一样没交代的东西，都算留了。
一件事说完了、人走了、镜头停在静态画面上，算没留。

**段里的剧情点**：这一段里所有值得单独指出来的时刻，不只是最强那一个。五类：

- 反转：观众此前对局面的理解被推翻——身份、实力、血缘、立场或财富翻转。
- 爽点：主角真的赢了——压制对手、身份被承认、对手认输。不是认知被推翻，
  是剧情里的胜利，两者常常不在同一秒。
- 悬念点：抛出一个问题、威胁或未知状况，让观众想知道接下来会怎样。规模
  不设门槛，只撑十几秒的小悬念也要报。
- 冲突：当面吵起来、动手、砸东西。
- 情绪：一个人崩溃、痛哭、失控。

**有旁人在看吗**：看第一步记录里那一刻的「有旁人在看吗」，不要自己推。

**主角在这一刻是**：这一刻的动作，是主角对别人做，还是别人对主角做。

- 施加方：主角揭穿、压制、反击、宣布、拒绝、动手。主角是这个动作的发出者。
- 承受方：主角被质问、被羞辱、被推倒、被要求道歉、被下跪。动作落在主角身上。
- 都不是：这一刻主角不在场，或者动作发生在两个配角之间。

同一件事里两边都有动作时，看这一刻的画面里谁在推进——被泼水之后立刻把杯子
夺过来泼回去，那一秒是施加方；只是被泼、镜头停在脸上，是承受方。

主角是谁，看整条素材里镜头跟着谁、观众的视角站在谁那一边。判不出主角就填
「都不是」，不要挑一个看起来像主角的人。

这两栏合起来分开两件事：主角当众赢和主角当众输。上报时不要混。

**高转化场景**：这一刻在演的是哪一种桥段。跟「哪一类」不重叠——「哪一类」
说的是动作性质，这一栏说的是桥段类型，同一刻两栏都要填。

- 当众反打脸：主角在旁人面前把先前压制自己的人反过来压制住
- 身份揭露：某个人的真实身份、血缘或实力被当场揭开
- 被迫亲密：一方被处境或另一方逼进亲密接触
- 家庭危机：亲子、婆媳、兄弟姐妹之间为钱、名分或孩子起冲突
- 权力失衡：一方靠地位、财富或职权单方面处置另一方
- 都不是：以上都套不上

套不上就填「都不是」，不要往最接近的那一类硬凑。这个词表是拿别人的经验
定的，装不下我们的素材是有可能的，「都不是」占比高本身就是信息。

一段里一处剧情点都没有，填空数组。

**亲密行为、暴力行为、羞辱行为**：这三栏记的是这一段里实际出现过的行为，
从下面三张词表里选词填，词表以外的一律不填，不要自己造词。行为名要跟词表
一字不差地照抄，不要改字、不要简写、不要加字。一段里同一种行为出现多次，
只报最早那一次。一段里一种都没有，填空数组。

你的任务是记录画面里发生了什么，不是评判尺度大小。不要打分，也不要说这一段
「尺度偏大」——档位由本地按这批素材的实际分布来分，你只管把行为名报准。

亲密行为词表：牵手、拥抱、搂腰、亲脸、性暗示台词、亲脖子、接吻、换衣脱衣、
内衣出镜、浴缸或淋浴同处、深吻、抚摸身体、上身裸露、床上同处、贴身纠缠、
壁咚或压制、跨坐、大面积裸露、明确性行为、器械或情趣用品、捆绑、主奴称呼

暴力行为词表：推搡、拉扯、抓手腕、言语威胁、摔东西、掀桌、打耳光、泼水、
下跪或被迫下跪、推倒在地、按在墙上、拳打脚踢、掐脖子、下药、注射、见血、
持械、开枪、绑架、致死、尸体出镜

羞辱行为词表：当众辱骂、被叫侮辱性称呼、被迫下跪或磕头、被迫道歉、
被当众揭穿隐私或短处、被泼水或泼食物、被吐口水、被当众赶走、被撕扯衣服示众、
被扔钱或被当面数钱打发、被当众解雇、被拒之门外、被当众贬低出身、
被要求叫尊称、被逼吃或喝不该吃的、被抢走或毁坏心爱之物、被当众否认身份或关系、
被围观嘲笑

三张词表有重叠的项。暴力记的是落在身体上的动作，羞辱记的是当众损人尊严的
动作，一件事可以同时是两者。当众泼一杯水，在暴力行为里报「泼水」，在羞辱
行为里报「被泼水或泼食物」，两栏都要有。

**亲密双方性别**：这一段的亲密场面发生在哪两个人之间。看第一步记录的人物
外观栏，那里写了性别。这一段没有任何亲密行为，填「无亲密场面」；有亲密行为
但看不出参与者性别，填「判不出」——不要按常见情况猜成男女。

**阶层落差**：这一段的两个主要人物之间，有没有明显的地位、财富或职权高低。
看得出来才填「有」，并在依据里放原文。判断看这些：谁在使唤谁、谁付钱、谁
穿制服或工装、谁的住所和车明显更好、称呼上有没有上下关系（Sir、总裁、
少爷、老板）。两个人看起来处境相当，或者这一段只有一个人，填「无」，依据
填空数组。
```

## 第三轮：悬念对答案

一次调用。输入：剧情时间线，加第二轮报上来的全部悬念点，按时间排好。

```
你要判断一条短剧广告素材里，每个悬念后面有没有给答案。

输入是整条素材的剧情时间线，加各处报上来的悬念点。悬念点是分段扫出来的，
每一处只看了它自己那一段，所以判不了答案在不在后面。

逐个悬念点往后找：后面哪一段的推进、或者哪一处别的剧情点，回答了它。找到了
填「给了」和那个绝对时间；到片尾都没回答的填「没给」，答案在哪填 null。

没回答的那些就是素材真正留给观众的钩。

## 规则

1. 只做答案归属。不新增悬念点，不删悬念点，不改它的时间和描述。
2. 输入里有几条悬念点，输出就有几条，顺序按时间。
3. 只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字。

## 输出格式

{
  "悬念点": [
    {"时间": 秒数,
     "是什么": "原样搬过来",
     "后面给答案了吗": "给了|没给",
     "答案在哪": 秒数 或 null,
     "凭什么算给了答案": "填「给了」时写一句，20 字以内；「没给」填 null"}
  ]
}
```

```
5. 只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字。

## 怎么判

**男频女频**：镜头跟着谁、观众的视角站在谁那一边。跟着女性主角、她的处境
是被欺负或被误解，是女频；跟着男性主角、他的能力或身份被低估，是男频。
两边都有戏份且分不出主次，填「通用」。

**核心矛盾**：这条素材从头到尾在争的那一件事。写具体的争夺对象——爵位、
孩子的抚养权、公司股份、一个人的身份是否被承认。不要写「善与恶的对抗」
这种。

**对手数量**：跟主角对着干的人有几个，数「对手是谁」那一栏里的人。同一
个家族但各自出手的算不同的人，比如继母和妹妹算两个。判不出对手是谁的
填 0。

**主角处境曲线**：主角在整条里的强弱怎么变。不是每段都写，只写处境发生
变化的那几段。第一段一定要写，最后一段一定要写。

- 占上风：主角在这一刻压制住了对方，或者拿到了他想要的
- 被压制：主角在这一刻被质问、被羞辱、被拒绝、被伤害
- 平等：两边势均力敌，或者这一段主角不在冲突里

一路都是占上风、或者一路都是被压制，都照实写，不要为了做出起伏去编。

**段的角色**：这一段在整条里起什么作用，不是这一段本身是什么。

- 开场：把观众留住，交代主角处在什么局面。通常是第 1 段
- 铺垫：不推进主线冲突，在给后面攒条件——换视角、交代关系、埋伏笔。
  这几段主角常常不出手
- 升级：冲突加码。主角处境更差，或者对手拿出更狠的手段
- 高潮：主角最主要的一次反击，或者整条最大的那个转折
- 收尾：高潮之后的处理，或者停在一个钩子上

一条素材可以有好几段升级，高潮通常是一到四段。整条只有一两段的素材，
照实标，不要为了凑齐五种角色硬分。

**每一段都要标，从第 1 段排到最后一段，中间不许跳号。**四十段的素材就
要给四十条。想不出某一段起什么作用的，标「铺垫」，「为什么」里写它在
交代什么。

**结构**：把上面的角色按顺序合并成几块，每块写这几段合起来在干什么。
角色相同但中间被别的角色隔开的，分成两块，不要合并。

**装配套路**：整条是怎么把段拼起来的。只能从下面这八条里选，选几条都
行，一条都对不上就填空数组。不许自己造新的条目，也不许改字。

| 套路 | 什么时候算 |
|---|---|
| 高潮前置 | 整条最强的一场戏在第 1 到第 2 段，后面回头补它的前因 |
| 一场戏切多段 | 连续三段以上在同一个地点，没换场景，把一件事拉长 |
| 多段小胜 | 连续三段以上，每段都是主角提出要求、对方抗拒、主角得手 |
| 连环断点 | 一半以上的段，结尾都留了没答的悬念 |
| 交替铺垫 | 主线段中间夹着换人物、换视角的段，两者交替出现 |
| 攒了再爆 | 连续三段以上主角被压制，之后有一段集中反击 |
| 强者兜底 | 最后两段里有人出面替主角出头，这个人不是主角也不是主要对手 |
| 单场到底 | 整条只有一个地点、一场戏，从头演到尾没换过 |

每选一条都要在「在哪几段」里给出起止段号，在「凭什么」里指出那几段
发生了什么。给不出段号的就不要选。

判据都写在表里，按表判，不要凭印象。比如只有两段在同一个地点，不算
「一场戏切多段」；主角自己反击不算「强者兜底」，得是别人出面。

同一条套路在不同段落各出现一次的，分开写两条，各给各的段号。

**结尾停在哪**：

- 没给答案：最后一刻抛出的问题到片尾都没交代，比如有人刚闯进来还没开口
- 给了答案：冲突解决了，关系定下来了，观众没有悬着的问题
- 停在动作中途：一个动作做到一半切断，比如手伸出去还没碰到

**结构上的缺口**：只能从下面这几条里选，选不出就填空数组。这一栏是照着
结构指出问题，不是评价好坏，所以不许自己造新的条目。

- 结尾给了答案，观众没有理由看下去
- 整条只有一个场面，没有铺垫也没有转折
- 主角处境从头到尾没有变过
- 有升级但没有高潮，冲突一直加码却没有反击
- 有高潮但前面没有铺垫，反击来得没有由头

**抓人的点**：这条素材靠什么让人看下去。三到四条，每条都要给出段号和秒数。
判断依据是这几样：第一个爽点或反转来得多快、多少段结尾留了悬念、高潮占了
多少段、结尾停在给了答案还是没给。
```
