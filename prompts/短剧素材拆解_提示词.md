# 海外短剧广告素材拆解提示词

三轮，每轮单独调用，第二轮按段循环。

---

## 第一轮：切段

输入：带时间码的字幕转写全文，每 15 秒一帧的截图外加每个黑场前后各一帧，本地检出的黑场和暗帧候选列表。

```
你要把一条短剧广告素材切成若干段。

输入是这条素材的字幕转写（带时间码）、每 15 秒一帧的截图外加每个黑场前后
各一帧，以及两份时间点列表。

你要做六件事：

1. 黑场列表里的每个时间点，写出它前后画面上什么变了：场景换了、人物换了、
   还是时间线跳了。这些是确定的段边界。
2. 暗帧候选列表里的每个时间点，判断它是渐变转场还是剧情里的暗光镜头。
   是转场就切成边界，并在边界依据里写明它是转场；不是就跳过，不用说明。
3. 这两个列表之外，还有场景、人物关系或时间线出现断裂的地方，补成新的
   边界，同样写出依据。
4. 切完之后，任何一段超过 120 秒，回到这一段里找场景更换或主要人物进出，
   再切一刀。找不到就保留，边界依据里写「单场景长段，未再切」。
5. 同一处边界只报一次。上一条为了压 120 秒去找的那个场景更换，很可能第 3
   条已经报过了——**两个起点不许是同一个数，也不许相差不到 1 秒**。报完
   通读一遍起点列表，重复的删掉，只留依据写得更具体的那一条。
6. **每段不短于 20 秒。**比这更短的画面变化不要单独成段，并进相邻的那一段，
   在那一段的边界依据里带一句就行。20 秒撑不起一段的人物和剧情叙述，切出来
   是噪声。整条素材只有几十秒时不受这条限制。

两个列表都为空时，说明整条是连续拍摄的一个故事。这种情况不要因为找不到
黑场就只报一段，按场景更换和主要人物进出去切，并遵守 120 秒上限。

每段只报起点。第一段的起点是 0。写不出依据的边界不要切。

起点报到 0.5 秒刻度，不要给两位小数。黑场列表里的时间直接用，不要自己改。

只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字：

{
  "段": [
    {"起": 0.0, "边界依据": "素材开头"},
    {"起": 78.5, "边界依据": "黑场 78.5 秒。画面从医院走廊切到婚礼现场，出场人物全部更换"},
    {"起": 165.0, "边界依据": "暗帧候选 165.0 秒，是渐变转场。字幕出现「三年后」，女主从被赶出家门变成回国"},
    {"起": 302.0, "边界依据": "上一段已达 137 秒，此处女主从卧室走进厨房，场景更换"}
  ]
}

暗帧候选判断成不是边界的，不要出现在段数组里，也不用单独说明。
```

## 第二轮：逐段详细描述

输入：这一段的视频切片（已切成独立文件，时间码从 0 起算）加这一段的字幕转写。

```
你要把一段短剧广告素材里发生的事，按时间顺序详细写下来。

你的工作是描述和记录，不是分析。不要判断这一段好不好、吸不吸引人，不要
给任何评分，也不要总结「这一段的作用是什么」。后面有别的环节做这些，它
要靠你写下来的东西来做，你漏掉的它补不回来。

## 规则

1. 时间从这一段的第 0 秒起算，报到 0.5 秒刻度，比如 12.0、12.5、13.0。
   不要报 12.37 这种两位小数。你对时间的分辨力到不了那一级，写出来的
   小数位是编的，本地会拿 ffmpeg 把你报的时间对齐到真实镜头切换点。
2. 事件记的是剧情上的变化，不是镜头上的变化。有人做出让局面变化的动作、
   说出改变局面的话、有人进场或离场，都记一条。**单纯的镜头切换、机位
   变化、正反打不算事件**——这些本地用 ffmpeg 数得出来，不用你报。
   在这个前提下宁多不少，密度不设上限：多记的后面能筛掉，漏记的补不回来。
3. 只写你在画面和字幕里看到的。看不出来的字段填 null，不要推测。
4. 描述写发生了什么，不写效果如何，也不写你的解读。
   ✗ 女主被当众羞辱，情绪张力拉满
   ✗ 这一刻暗示两人关系不一般
   ✓ 婚礼上婆家人把女主的行李扔到门外，宾客回头看
5. 人物用字幕或台词里出现的称呼，比如「Isla」「继姐」。认不出名字的写
   外观加身份，比如「穿黑西装的中年男人」。不要自己编名字。
6. 描述和叙述用中文写，台词字段照抄原文，不要翻译。
7. 只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字。

## 输出格式

{
  "段序号": 整数,

  "场景": {
    "地点": "15 字以内，比如「卧室」「医院走廊」「婚礼宴会厅」。这一段里镜头换过地点的，写占时长最多的那一个。同一条素材里同一个地方只用一个名字"
  },

  "人物": [
    {"称呼": "字幕或台词里怎么叫这个人",
     "外观": "20 字以内，性别、年龄段、穿着",
     "首次出现": 秒数}
  ],

  "事件": [
    {"时间": 秒数,
     "画面": "这一秒画面上是什么，谁在做什么，30 字以内",
     "台词": "这一刻的台词原文，没有台词填 null",
     "在场人数": 整数,
     "有旁人在看吗": "有|无",
     "这一刻发生了什么变化": "用你自己的话写，30 字以内，不要用固定词表"}
  ],

  "屏幕上的文字": [
    {"时间": 秒数,
     "持续到第几秒": 秒数,
     "内容": "屏幕上出现的非台词文字，照抄原文",
     "位置": "画面中间|画面下方|画面上方|角标"}
  ],

  "段落叙述": "这一段从头到尾讲了什么，按时间顺序写成 150 字以内的连贯叙述。这一段的人物关系、身份、处境如果在台词里交代过，写进来；没交代过就不写。",

  "这一段最后一个镜头": "画面上是什么，20 字以内",

  "声音": {
    "背景音乐": "全程有|部分有|没有",
    "音乐变化": [
      {"时间": 秒数,
       "怎么变": "起|停|换曲|变强|变弱"}
    ],
    "音效强调": [
      {"时间": 秒数,
       "是什么声音": "10 字以内，比如「耳光」「玻璃碎」「心跳」「刹车」"}
    ],
    "静音段": [
      {"起": 秒数,
       "止": 秒数}
    ]
  }
}

## 字段说明

- 声音「背景音乐」：只判有没有配乐垫底，不判曲风也不判情绪。人声和环境音
  不算配乐。整段听不到任何配乐填「没有」。
- 声音「音乐变化」：配乐起、停、换曲、明显变强变弱，各记一条并给秒数。没有
  变化就给空数组。这一项对着剪辑里的音频轨，改动位置能直接找到。
- 声音「音效强调」：单独加强过的声音事件，比如耳光、玻璃碎、心跳、刹车、
  枪响。持续的环境音（雨声、人群嘈杂）不算。听不出具体是什么声音的不写。
- 声音「静音段」：连续两秒以上既没有台词、也没有配乐和音效的段落，写起止
  秒数。全段没有就给空数组。

- 人物「称呼」：优先用台词里叫的名字。同一个人在这一段里被叫过两种称呼，
  都写上，用顿号隔开。
- 场景「地点」：同一条素材里，同一个地方从头到尾只用一个名字。第 3 段写了
  「医院走廊」，第 8 段又回到这条走廊，还写「医院走廊」，不要改成「走廊」
  或者「豪华走廊」。后面有一步要靠连续几段地点相同来判断一场戏被切成了几段，
  换名字就判不出来。拿不准前面写过什么，就用最短的通名，比如「客厅」「庭院」
  「宴会厅」。
- 事件「有旁人在看吗」：这一刻现场除了当事的两个人，还有没有第三方在场
  并且看得到。这是看画面就能数的，不要靠推测。
- 事件「这一刻发生了什么变化」：这是最重要的一栏。写这一秒之后局面跟这
  一秒之前有什么不一样——谁知道了什么、谁失去了什么、谁的态度变了、谁
  进来了。不要往「反转」「爽点」「高潮」这类词上靠，用你自己的话把具体
  的变化写出来。
- 屏幕上的文字：包含标题字卡、旁白字幕之外的说明文字、下载引导、平台
  名称、解锁和订阅提示。台词字幕不算，台词写在事件里。
  「持续到第几秒」报它从画面上消失的时刻。一直挂到这一段结束的，填这一段
  的时长。常驻的角标和只闪一下的钩子对观众的作用不一样，光有出现时刻分不
  出来。看不出什么时候消失就填 null。
- 段落叙述：写给一个没看过这条素材的人。人物关系和身份只写台词交代过的，
  台词里没说的一律不写——这一段没交代，别的段会交代，不用你补。
```

## 第三轮：整条素材的呈现形式

输入：全片均匀抽 10 帧加片头 3 帧（判字幕和语音形式用），另加片尾 30 秒的视频切片（找结尾字卡用）。

```
你要判断一条短剧广告素材的呈现形式，另外找出片尾的结尾字卡。

呈现形式看那批截图。结尾字卡看片尾切片，切片的时间码从 0 起算，你报出的
时间也从 0 起算，本地会把偏移加回去。

时间报到 0.5 秒刻度，不要给两位小数。

只输出 JSON 本身，不要用代码块包裹，不要在前后加说明文字：

{
  "字幕形式": "全程硬字幕|部分片段有字幕|无字幕",
  "字幕语言": "英文|中文|其他（写出语种）|无字幕",
  "语音形式": "英语配音|原声加字幕|只有音乐|无声",

  "结尾字卡时间": 秒数 或 null,
  "结尾字卡形式": "字卡|App 下载引导|无",
  "剧情停下的时间": 秒数 或 null
}

- 硬字幕指烧进画面、观众无法关闭的字。「部分片段有字幕」要在均匀抽的
  10 帧里真的看到有字幕的帧和没字幕的帧，只是某一帧没人说话不算。
- 英语配音指人物讲英语。原声加字幕指人物讲的不是英语、屏幕上有字幕。
- 结尾字卡指剧情停下之后、屏幕上出现的那张让观众去看后续的画面，通常是
  一行字或一个下载引导。付费发生在 App 里，素材上看不到，不用去找。
  整条素材通常只有一处，在最后几秒。找不到就填 null 和「无」。
- 剧情停下的时间和结尾字卡时间常常是同一秒：剧情一直演到字卡出现的那一
  刻。两个都照实报，不要为了让它们错开去改数。
```
