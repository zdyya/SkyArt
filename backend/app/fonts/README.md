# 花字字体

放**免费商用**中文/拉丁字体（.ttf/.otf），文件名对应 `postprocess.py::_FONTS`，编辑页预览和导出渲染都用这批文件。没放对应文件时中文自动退回 macOS 系统字体（宋/黑/Hiragino），**中文一定能渲染、不会出方框**。

## 已打包（海外投放常用，全部 SIL OFL 免费商用，来自 Google Fonts）

| 文件 | 字体 | 用途 | 授权 |
| --- | --- | --- | --- |
| `Anton.ttf` | Anton | 冲击力标题/卖点大字 | SIL OFL 1.1 |
| `BebasNeue.ttf` | Bebas Neue | 高窄全大写标题 | SIL OFL 1.1 |
| `Poppins.ttf` | Poppins Bold | 现代黑（社媒最常用） | SIL OFL 1.1 |
| `AlfaSlab.ttf` | Alfa Slab One | 粗厚板衬线 | SIL OFL 1.1 |
| `Bangers.ttf` | Bangers | 漫画冲击（戏剧感） | SIL OFL 1.1 |
| `Lobster.ttf` | Lobster | 粗手写花体 | SIL OFL 1.1 |
| `Pacifico.ttf` | Pacifico | 圆润手写 | SIL OFL 1.1 |
| `PlayfairDisplay.ttf` | Playfair Display | 优雅衬线（言情剧名） | SIL OFL 1.1 |

来源：github.com/google/fonts（ofl/ 目录）。SIL OFL 允许免费商用、可随产品打包分发，不得单独售卖字体本身。

## 中文（系统字体，未打包）

宋体 / 黑体(STHeiti) / 圆润体(Hiragino Sans GB) 用 macOS 系统字体，无需放文件。想要装饰性中文花字（书法/综艺/手写），放对应可商用 TTF 进来即可（思源、阿里巴巴普惠体、站酷快乐体等），并在本表补一行授权来源。
